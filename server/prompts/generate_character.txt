MODE: Character

A character is a toolbox block: one line in the form KEY = (block) that a Perchance generator expands wherever [KEY] appears. It fixes who the person is so that outfits, scenes, and overlays can change around them. In this mode the EXPAND rule applies to the body, face, hair, signature marks, and clothing bias only.

OUTPUT SHAPE, one continuous line, zero line breaks:
KEY = (Name; age and sex or species; skin; hair; eyes; build; marks and signature accessories; primary clothing style and palette; keep-constant anchors; vibe)

- KEY is the key the input gives. When the input gives none, use the short name in capitals.
- Order is priority. Name first, then the identity anchors that must never drift (hair, eyes, skin, a signature such as a choker, glasses, a tail, a scar), then build, then clothing as a style bias rather than one fixed outfit, then the anchors line, then the vibe.
- Nested parentheses add emphasis, as in ((messy shoulder length poofed out) mane of hair). Two levels at most. Every parenthesis closes.
- Curly braces with pipes give Perchance alternatives, as in {faint glowing scales| glowing runes| bolts of energy}, and a ^n weight marks the favored option, as in {^2||visible nipple}. Only in variation 3, only on hair and clothing.
- Numbers are allowed for age and height in a block, the way the locked blocks use them. Everything else stays sensory.
- The anchors line reads like: keep hair color/length, glasses, eye hue fixed while outfits shift. Then the vibe, introduced with a semicolon: ; serious, intelligent, nerdy vibe. Never an em dash.
- Clothing is a bias: primary colors, weight, how revealing, one or two garment types. A full outfit belongs to Costume mode.
- Setting from the input is left out. A block carries no place.
- Attire from the input becomes the clothing bias, kept verbatim where it is already visual.
- A block the input gives verbatim (a pasted sheet's own wording, a [TAG]) is kept verbatim.

VARIATIONS
Three blocks for the same character, from the same input.
Variation 1: compact anchor block, about 60 words. Name, the anchors that must never drift, clothing bias in one clause, anchors line, vibe.
Variation 2: full block, about 120 words. Everything variation 1 has plus build, marks, expression, and a fuller clothing bias.
Variation 3: full block with Perchance alternatives, about 130 words. The same as variation 2 with one {a|b|c} list on hair styling and one on clothing, three options each, every option consistent with the anchors.

Before returning, reread each block: every parenthesis closes, the line has no line breaks, "or" appears nowhere, nothing is negated, the anchors line names the features that must stay fixed.
